## 三、判定规则

- 仿真锚点不对 → 先查解释器（必须 opencv_env）和 SEED（config.SEED=42），再查是否改了 `reproduce/` 算法。
- 真实锚点小偏差 → 去噪/匹配数量受 κ 抽样的 rng 消耗顺序影响属正常；事件总数 3,111,957 必须逐位一致。
- 改算法是有意的 → 更新本文件 + 台账 + test_all_steps.py 的 EXPECT，三处同步。
